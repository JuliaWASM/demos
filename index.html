Julia → WebAssembly demos

Live demos of Julia code compiled to WebAssembly with WasmCodegen.jl, running entirely in your browser.

  • Tyler-like map

    An interactive slippy map with live OpenStreetMap tiles. Camera, tile selection, PNG decoding and Makie plots all run as Julia compiled to wasm.

    Requires: JSPI (Chrome 137 or newer, desktop recommended) and network access to tile.openstreetmap.org. About 2.3 MB download.
